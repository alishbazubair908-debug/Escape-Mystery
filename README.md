# 🔐 Escape Mystery

An escape-room style puzzle game built in Scratch — solve riddles, unlock a hidden chest, and battle your way through a boss fight to win.

▶️ **[Play it now on itch.io](https://shahidapbc2gmailcom.itch.io/escape-mystery)**

## 🎮 About the Game

You're trapped in a mystery room. To escape, you'll need to solve a series of riddles, unlock a chest, and open the door — but standing between you and freedom is a final boss fight you'll need to win.

## ✨ Features

- 🧩 **3 riddles** to solve as you progress through the room
- 🔒 **Interactive chest & door mechanics** — the chest opens and the door unlocks as you solve each puzzle
- 🥊 **Full boss-fight combat system** — a separate fighting mode against a CPU opponent, complete with:
  - Live health bars for both player and CPU
  - Punch, kick, and defend/block actions
  - Knockout detection and win/lose screens
- 🖥️ Menu screen, instructions screen, and multiple levels
- 🎨 Custom AI-generated character art and sprites
- 🔊 Full sound effects and background audio

## 🕹️ How to Play

## 🛠️ Built With

- **Scratch** — visual block-based programming
- Custom sprite art (AI-generated character assets)
- Original variables-driven game logic for riddles, combat, and health tracking

## 📌 Notes

This project combines puzzle-solving mechanics with an original real-time combat system — both built entirely from Scratch's block-based logic, without any code extensions.
